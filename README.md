2. Cách khởi động project
- khởi tạo database bằng file data.sql trong thư mục "resources" (exam-prep-backend\src\main\resources)
- đổi mật khẩu liên kết database trong file application.yml để kết nối dtabase
- cài đặt các thư viện maven trong file pom.xml
- Run "ExamPrepBackendApplication" để khởi động project
